# EagleDoc-GUI
Graphical Standalone CURL App for Eagle Doc and its learding api endpoints


Run via either:
1. Manual installation:
Open console, run:
pip install fastapi uvicorn python-dotenv httpx jinja2 python-multipart
uvicorn main:app --reload

2. Use native Windows Installation
Double click "setup.bat" and then run "start.bat"

3. Use linux/mixed Installation
Open console, run:
pip setup.py
pip start.py
