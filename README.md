# EagleDoc-GUI

Graphical Standalone cURL App for EagleDoc and its leading API endpoints.

---

Choose one of the installation and setup methods below based on your operating system and preferences:

1. Manual Installation

Open your terminal/console and run the following commands:

```bash
# Install dependencies
pip install fastapi uvicorn python-dotenv httpx jinja2 python-multipart

# Start the application
uvicorn main:app --reload
```

---

2. Use native Windows Installation

Double click "setup.bat" and then run "start.bat"

---

3. Use linux/mixed Installation (also works for Windows)

Open console, run:
```bash
# Setup dependencies
python setup.py

# Launch application
python start.py
```
